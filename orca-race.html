        Why it’s fair

        • The race code and the racer list decide everything. They feed a seeded random generator; nothing random happens during the race.
        • Post the code and the racer list before the race. Anyone can type the same code with the same racers into Replay with code and watch the exact same race and winner.
        • Lane order doesn’t matter: Shuffle lanes moves orcas around but can’t change the result. The race length only stretches time.
        • The racers # fingerprint next to the code changes if anyone is added, removed or renamed.
